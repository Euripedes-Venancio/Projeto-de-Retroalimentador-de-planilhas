# Projeto-de-Retroalimentador-de-planilhas
Projeto de retroalimentador de planilhas realizado no meu período de estágio.

Ele tem como objetivo, automatizar, acelerar e trazer mais praticidade para o setor financeiro da empresa.

Ele lê a saída dos arquivos no formato CSV gerados a partir de uma aplicação gerada previamente pela empresa, após esta leitura, ele extrai as informações e alimenta uma planilha principal.
